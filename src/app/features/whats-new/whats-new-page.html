APIs experimentales y roadmap

  • Platform Navigation API. El Router puede delegar operaciones de navegación al navegador. La disponibilidad y el comportamiento dependen del navegador. Referencia del Router.
  • WebMCP. Angular explora cómo declarar herramientas de una aplicación para agentes del navegador. El estándar y las APIs pueden cambiar incluso entre versiones menores. Guía de WebMCP.
  • Recursos del Router. La vista previa de Angular 22.2 permite explorar recursos asociados a rutas. Revisa la API y el roadmap antes de depender de ese contrato. Referencia de recursos del Router.

Cualquier ensayo futuro puede vivir en una rama aislada con su propia configuración. El roadmap oficial describe el trabajo en curso y las prioridades del equipo.

Herramientas de Angular para GitHub Copilot

  1. Abre el repositorio en VS Code con GitHub Copilot activado. Revisa AGENTS.md y .github/copilot-instructions.md desde las personalizaciones del chat para conservar las convenciones de Atlas y detectar reglas duplicadas.
  2. La skill de Atlas cubre su interfaz. Para ampliar la cobertura con patrones oficiales de signals, rutas y forms, revisa angular-developer en el repositorio oficial. Si el equipo decide adoptarla, copia su carpeta revisada bajo .github/skills y comprueba que Copilot la reconoce. Revisa la referencia de Angular que usa la skill para evitar sugerencias para una versión posterior. Angular Agent Skills · Personalizaciones de Copilot.
  3. El CLI MCP ya está declarado en .vscode/mcp.json. Antes de iniciarlo desde MCP: List Servers, revisa el comando y las herramientas disponibles. Para una evaluación, usa la CLI local instalada con npm exec --offline -- ng mcp --read-only --local-only como comando y argumentos del servidor. Esos flags limitan las herramientas que el servidor registra. Revisa también los permisos del agente, el acceso al repositorio y el uso de la red por parte de Copilot.
