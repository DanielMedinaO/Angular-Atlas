RxJS en profundidad

Observa cómo se crean, combinan y cancelan los flujos asíncronos en Angular.

Fundamentos de RxJS

Observable
Representa una fuente de valores durante el tiempo. Puede emitir de forma síncrona o asíncrona.
Observer
Recibe next por cada valor, error si el flujo falla o complete si termina con éxito. Tras una notificación terminal se cierra la suscripción.
Subscription
Es el vínculo devuelto por subscribe(). Usa unsubscribe() para liberar sus recursos cuando ya no necesitas el flujo.

Creación y composición

  • new Observable() permite definir un productor y devolver su función de limpieza.
  • of() emite cada argumento y completa. Un array pasado como argumento se emite como un solo valor.
  • from() convierte una fuente compatible, como un iterable o una Promise, en un Observable. Con un array emite sus elementos por separado.
  • interval() emite una secuencia periódica a partir de cero. take() puede limitarla.
  • fromEvent() escucha eventos de una fuente como un elemento DOM y retira el listener al cancelar.

pipe() aplica operadores en orden y devuelve un Observable derivado. En values$, primero filtra el 1 y luego transforma el 2 y el 3 en 20 y 30. El ejemplo de fromEvent() supone que button referencia un botón del DOM.

Observables fríos y calientes

Una fuente fría inicia una ejecución por suscripción. Dos suscriptores a interval() tienen relojes independientes. Una fuente caliente comparte la producción con sus observadores. En los eventos del DOM, cada suscripción registra su listener, pero el clic ocurre de forma independiente a esos listeners. Los Subjects permiten distribuir una emisión a varios observadores.

Promise, Observable y Signal

Promise
Representa un resultado único o un rechazo, normalmente de una operación ya iniciada. Úsala con await cuando basta con un resultado. La cancelación depende de la API que inició el trabajo, como una que acepte AbortSignal.
Observable
Representa cero o más valores y permite cancelar la suscripción. Úsalo cuando necesitas combinar eventos, aplicar operadores de tiempo o reemplazar una operación por otra.
Signal
Expone un valor actual mediante una lectura síncrona. Úsalo para estado de interfaz y valores derivados, como el total de un carrito. Usa la interoperabilidad de Angular cuando necesites conectar ese estado con un flujo.

Laboratorio B · Subject Explorer

  • Subject entrega emisiones nuevas a sus suscriptores activos.
  • BehaviorSubject necesita un valor inicial (aquí, 0) y entrega el valor actual inmediatamente al suscribirse a la fuente activa.
  • ReplaySubject entrega el historial del búfer al suscribirse. Aquí guarda hasta dos emisiones, en el orden original, y comienza vacío.

Laboratorio C · RxJS Operator Playground

Los cuatro operadores reciben el mismo flujo A, B y C. Cambia las pausas entre eventos y compara el orden de los resultados y de las finalizaciones. Con los intervalos iniciales, switchMap entrega C, concatMap entrega A → B → C, mergeMap entrega C → B → A y exhaustMap entrega A.

Usa switchMap para búsquedas donde importa la consulta más reciente, concatMap para escrituras ordenadas, mergeMap para tareas independientes y exhaustMap para evitar envíos repetidos mientras sigue activo el anterior.
