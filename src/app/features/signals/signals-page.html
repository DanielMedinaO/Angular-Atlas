Signals

Los signals son contenedores de valor que notifican a Angular cuándo cambian, permitiendo una detección de cambios granular sin depender de Zone.js.

Creando un signal

La función signal() crea un valor reactivo con un estado inicial. Se lee invocándolo como función, count(), y se actualiza con set() o update(), nunca mutando el valor directamente. 

const count = signal(0);

count();         // 0
count.set(5);     // reemplaza el valor
count.update(v => v + 1); // deriva el nuevo valor del anterior

Derivando estado con computed()

computed() crea un signal de solo lectura cuyo valor se recalcula de forma perezosa cada vez que alguna de sus dependencias cambia, manteniendo la lógica de derivación pura y predecible. 

const count = signal(0);
const doubled = computed(() => count() * 2);

doubled(); // se recalcula solo cuando "count" cambia
